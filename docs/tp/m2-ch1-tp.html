Travaux pratiques : Système d'exploitation (Windows 11)

Matériel : un poste sous Windows 11 par binôme. Durée indicative de chaque TP : 30 à 45 minutes. Répondre aux questions sur la fiche réponse ou dans un fichier texte selon les consignes du professeur.

TP 1 : Découverte du bureau et du menu Démarrer

Objectif : identifier les éléments du bureau de Windows 11 et utiliser la souris.

  1. Allumer l'ordinateur et ouvrir une session. Noter le nom du compte utilisé.
  2. Repérer et nommer sur la fiche : le bouton Démarrer, la zone de recherche, la barre des tâches, la zone de notification, la Corbeille.
  3. Ouvrir le menu Démarrer. Citer trois applications épinglées.
  4. Cliquer sur « Toutes les applications » et lancer la Calculatrice. La fermer avec Alt + F4.
  5. Dans la zone de recherche, taper « Bloc-notes » et ouvrir l'application.
  6. Pointer l'heure dans la zone de notification : quelle information apparaît ?
  7. Faire un clic droit sur une zone vide du bureau. Citer quatre commandes du menu contextuel.
  8. Créer un raccourci du Bloc-notes sur le bureau (Démarrer › clic droit sur Bloc-notes › Ouvrir l'emplacement du fichier, ou glisser l'application vers le bureau). Observer la petite flèche.

TP 2 : Manipulation des fenêtres

Objectif : maîtriser les boutons de contrôle, les dispositions d'ancrage et le passage d'une fenêtre à une autre.

  1. Ouvrir l'Explorateur de fichiers (Windows + E), le Bloc-notes et la Calculatrice.
  2. Sur la fenêtre de l'Explorateur, utiliser successivement les boutons Réduire, Agrandir, Restaurer.
  3. Déplacer la fenêtre du Bloc-notes en faisant glisser sa barre de titre.
  4. Redimensionner la fenêtre du Bloc-notes en faisant glisser un de ses bords.
  5. Placer l'Explorateur à gauche (Windows + ←) et le Bloc-notes à droite (Windows + →).
  6. Pointer le bouton Agrandir d'une fenêtre : dessiner sur la fiche les dispositions proposées. En choisir une prévue pour trois fenêtres.
  7. Passer d'une fenêtre à l'autre avec Alt + Tab.
  8. Afficher le bureau avec Windows + D, puis appuyer de nouveau sur Windows + D. Que se passe-t-il ?
  9. Ouvrir le Gestionnaire des tâches (Ctrl + Maj + Échap). Relever le pourcentage d'utilisation du processeur et de la mémoire. Quel lien avec le cours (partie 1.5) ?

TP 3 : Personnaliser Windows 11

Objectif : utiliser l'application Paramètres.

  1. Ouvrir les Paramètres (Windows + I).
  2. Personnalisation › Arrière-plan : changer l'image du bureau.
  3. Personnalisation › Couleurs : passer du mode clair au mode sombre, puis revenir.
  4. Personnalisation › Barre des tâches › Comportements : aligner la barre des tâches à gauche, puis la remettre au centre.
  5. Système › Affichage : noter la résolution d'écran.
  6. Système › Informations système : relever le nom de l'appareil, le processeur, la mémoire RAM installée et l'édition de Windows.
  7. Heure et langue : vérifier la date, l'heure et la langue du clavier.
  8. Remettre tous les réglages d'origine avant de quitter.

TP 4 : Créer une arborescence

Objectif : créer des dossiers et organiser une arborescence.

Dans Documents, créer l'arborescence suivante (remplacer NOM par votre nom) :

Documents
└── TC_NOM
    ├── Francais
    ├── Maths
    └── Informatique
        ├── Cours
        ├── Exercices
        └── TP
  1. Ouvrir l'Explorateur de fichiers et se placer dans Documents.
  2. Créer le dossier TC_NOM (clic droit › Nouveau › Dossier, ou Ctrl + Maj + N).
  3. Créer les sous-dossiers en respectant l'arborescence.
  4. Renommer le dossier Francais en Langues (F2).
  5. Écrire le chemin d'accès complet du dossier TP (le copier depuis la barre d'adresse).
  6. Afficher le volet de navigation : développer l'arborescence pour voir tous les dossiers créés.

TP 5 : Opérations sur les fichiers

Objectif : créer, renommer, copier, déplacer et supprimer des fichiers.

  1. Afficher les extensions des fichiers : Afficher › Afficher › Extensions de noms de fichiers.
  2. Avec le Bloc-notes, créer un fichier contenant « Le système d'exploitation gère les ressources de l'ordinateur ». L'enregistrer sous le nom definition.txt dans Informatique\Cours.
  3. Avec Paint, dessiner un logo simple et l'enregistrer sous logo.png dans Informatique\TP.
  4. Copier definition.txt dans le dossier Exercices (Ctrl + C, Ctrl + V). Vérifier qu'il existe toujours dans Cours.
  5. Déplacer logo.png du dossier TP vers le dossier Langues (Ctrl + X, Ctrl + V). Vérifier qu'il n'est plus dans TP.
  6. Renommer la copie de definition.txt en resume.txt.
  7. Afficher les propriétés de logo.png : noter son type, sa taille et sa date de création.
  8. Changer le mode d'affichage du dossier en « Détails » puis trier par taille.
  9. Sélectionner deux fichiers non contigus avec Ctrl, puis tous les fichiers avec Ctrl + A.

TP 6 : Corbeille, recherche et compression

Objectif : récupérer un fichier supprimé, rechercher et compresser.

  1. Supprimer resume.txt (touche Suppr). Ouvrir la Corbeille et le restaurer. Où réapparaît-il ?
  2. Dans le dossier TC_NOM, rechercher tous les fichiers texte en tapant *.txt dans la zone de recherche. Combien en trouvez-vous ?
  3. Compresser le dossier Informatique : clic droit › Compresser vers › Fichier ZIP. Comparer la taille du dossier et celle du fichier .zip.
  4. Extraire le fichier ZIP dans un dossier nommé Sauvegarde.
  5. Copier le fichier ZIP sur une clé USB (si disponible), puis le supprimer de la clé : passe-t-il par la Corbeille ? Conclure.
  6. Bilan : compléter un tableau récapitulatif des raccourcis utilisés pendant les TP.
